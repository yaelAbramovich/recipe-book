# ספר המתכונים (Recipe Book)

PWA לארגון מתכונים ויצירת רשימת קניות מאוחדת — להעתקה או לשליחה בוואטסאפ. הכול בעברית ו־RTL.

- **הוספת מתכון:** טקסט חופשי, קישור לאתר (קורא schema.org/Recipe), או קובץ (תמונה/צילום מסך עם זיהוי טקסט בעברית, pdf, txt, html). אחרי הזיהוי יש מסך עריכה לתיקון.
- **רשימת קניות:** מסמנים מתכונים (אפשר לשנות מספר מנות), והמצרכים מתאחדים (3 ביצים + 2 ביצים = 5, גרם→ק"ג), מחולקים לפי מחלקות בסופר.
- **שיתוף:** העתקה, וואטסאפ (`wa.me`), או תפריט השיתוף של המכשיר. אפשר גם להוסיף פריטים ידנית.
- **נתונים:** נשמרים ב־`localStorage` במכשיר. גיבוי/שחזור כקובץ JSON מהמסך הראשי.

## תמונות (OCR)
תמונה/צילום מסך נקראת במכשיר עם Tesseract (מודל עברית `best_int`, נטען פעם אחת ונשמר). לפני הזיהוי מסמנים את אזור המתכון בתמונה — זה משפר את הדיוק משמעותית בצילומי מסך מאינסטגרם וכד'.
עמודות (מצרכים | הכנה) מזוהות לפי רווח אנכי וקוראות כל אחת בנפרד. ידוע: OCR מבלבל ספרות (½ ← 4, 200 ← 0), ולכן יש הודעת "בדקי כמויות" ותיקון אוטומטי ל־"4 כוס/כפית" ← ½ (בתמונות בלבד).

## ייבוא מקישור
האפליקציה סטטית, ולכן קריאת דפים חיצוניים דורשת פרוקסי. הסדר: `api/fetch` (פונקציית Vercel בפרויקט, אם מפרסמים שם) ← `allorigins` ← `r.jina.ai`. כשהאתר חוסם — מדביקים את הטקסט בלשונית "טקסט".
פרסום ב־GitHub Pages עובד, אבל ללא `api/fetch` הייבוא מקישורים פחות יציב.

## פיתוח
- הרצה מקומית: `python3 -m http.server 8137`
- עדכון גרסה: להעלות `VERSION` ב־`sw.js` (ואת `?v=` ב־`index.html`/`CORE`), ואז commit + push.
- אייקונים: `icon.svg` → `qlmanage -t -s 512 -o . icon.svg`, ואז `sips -z` לגדלים.
- הערה: בטקסט הנשלח לוואטסאפ אין אימוג'י — `wa.me` משבש אותם.
